# GitHub Copilot Workshop Exercises

## Introduction
- Download the code to a folder on your computer by cloning the repo or downloading the files.
- Launch VS Code and open the folder where your code is located.
- To run the website, go to the terminal (View -> Terminal), and type in dotnet run.  Once the code is done compiling you will see a url that you can click on to launch the app.

## Exercise #1
Using GitHub Copilot, determine what the application does and what components it uses.

After you completed this GitHub Copilot task, answer the following questions.

**Answer the following questions:**
1. What kind of application is this? What framework is it using? What language is it written in?
2. Where does the application get the data from? Describe the database it uses.
3. What libraries is it using, and what does it use these libraries for?
